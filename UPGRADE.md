# EFEL production upgrade

The upgrade starts from main at 722f1d2, served as efel-ui06. The frontend remains static GitHub Pages with Supabase Auth, PostgREST, Realtime and RPCs. Competition rules and the data model remain in the existing SQL. The frontend release uses cache version efel-prod01.

## Player media

The media catalogue maps stable EFEL card IDs to verified Wikimedia Commons files and creator and license metadata. The ingestion tool accepts manually identified biographies and direct Commons files. It never uses fuzzy name search. A verified photo can apply to another card when the numeric base ID and exact catalogue name agree. The base ID estimate uses the observed card encoding, with a version in blocks of 16,777,216. Twenty base IDs have differing name spellings and are excluded from automatic cross-name reuse.

Existing eFootball artwork takes priority in the thumbnail and full card. Shared portrait rendering provides a photo, assigned artwork crop or initials for avatars and smaller contexts. A central credits page and expandable detail credit provide creator, source, license and modification information. The initial Müller, Livramento, Abraham and Adams mappings were checked against Commons and moved to local WebP files.

See [media-coverage.json](media-coverage.json) for the catalogue, manager-league and automated-roster snapshots and the IDs rejected or deferred during ingestion. Its original portrait count measures manifest entries. Missing means no real portrait mapping, including cards with original artwork.

To import curated candidates, install Pillow, review the identities file, and run from the checkout.

    python tools/ingest-media.py --report media-coverage.json --limit 24

Supply a private temporary JSON file with group names mapped to arrays of known roster card IDs through --rosters. The importer prioritizes those IDs, then highest rating. Use --coverage-only to check the current manifest offline. Review any newly generated images alongside their source page before publication. Wikimedia can rate-limit requests. The importer retains downloaded records and records failures so a later run can resume.

## Club crests

All 24 mapped files returned HTTP 200. The PNGs have transparency, preserve proportions in the common rendering box and were visually matched to their clubs. The release pins these files to the reviewed upstream snapshot. Ajax uses the current classic crest and Liverpool uses the club’s digital Liver Bird. The source repository does not establish a blanket redistribution license for club marks. The existing external delivery uses fallback rendering and independent-league attribution.

## Running browser checks

Install Playwright and start a static server in the checkout.

    EFEL_BASE_URL=http://127.0.0.1:8765/ node tests/browser.cjs

Optional variables include CHROMIUM_PATH and EFEL_SCREENSHOTS. The harness supplies its own in-browser Supabase client and isolated league fixtures. It checks all 12 manager routes across seven viewport widths, manager and admin navigation, player search and detail, pagination, a price past the first backend page, and calls generated by the bid, transfer and score interfaces. Real accounts and production writes are outside this suite. Overflow is checked at the document level. Backend concurrency testing remains separate.

## Security

The deployment changes user-facing URL handling and fallback rendering, sign-in state transitions and admin navigation. These controls complement the existing RLS and RPC authorization. The production audit inspected all 41 signed-in SECURITY DEFINER findings, current table policies and RPC grants with read-only queries. No production user, roster, budget, fixture or match data was written for this release.
